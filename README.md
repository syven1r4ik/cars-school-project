🚗 Car Management Dashboard

A modern admin dashboard for managing a car fleet. This project implements a full server-side rendered CRUD application with local database integration, wrapped in a clean, professional user interface.

✨ Key Features

Full CRUD Operations: Create, Read, Update, and Delete cars individually or in bulk.

Modern UI/UX: Clean, light-themed design featuring glassmorphism effects, smooth hover animations, and a responsive layout using CSS Flexbox.

Dynamic Rendering: HTML is generated on the fly on the server side using the Handlebars templating engine, keeping the client-side lightweight.

Local Database: Powered by NeDB (a NoSQL document-oriented datastore similar to MongoDB) for persistent data storage.

🛠 Tech Stack

Backend: Node.js, Express.js

Database: NeDB

Frontend: Handlebars (.hbs), HTML5, CSS3
